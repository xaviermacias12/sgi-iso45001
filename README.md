# Sistema de Gestión Integral (SGI) - Norma ISO 45001

## Descripción del Proyecto
Aplicación web desarrollada para la gestión integral de Seguridad y Salud en el Trabajo bajo los lineamientos de la norma **ISO 45001:2018**. El sistema fue implementado en el **Tecnológico Nacional de México (TecNM) - Campus Nochistlán**, con el objetivo de digitalizar, organizar y dar seguimiento a los procesos administrativos y de seguridad de la institución.

## Características Principales
*   **Gestión Documental:** Control y almacenamiento de documentos obligatorios de la norma.
*   **Seguimiento de Indicadores:** Paneles para visualizar el cumplimiento de objetivos de seguridad.
*   **Registro de Incidentes:** Módulo para reportar y dar seguimiento a accidentes o cuasi accidentes.
*   **Gestión de Usuarios y Roles:** Diferentes niveles de acceso para administradores, coordinadores y personal.
*   **Auditorías Internas:** Herramientas para planificar y registrar auditorías de cumplimiento.

## Tecnologías Utilizadas
*   **Backend:** Laravel (PHP)
*   **Base de Datos:** MySQL
*   **Frontend:** Blade, Tailwind CSS, JavaScript (o Bootstrap, dependiendo de lo que hayas usado)
*   **Servidor Local:** XAMPP / Laragon
